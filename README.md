# Учебный проект Погорельцева Романа Олеговича

### Проект создан для обучения работы с классами
### В проекте реализованы следующее:
1. [main.py](src/main.py) - базовый модуль для проверки работы классов. Классы импортированы из [class_config.py](src/class_config.py)
2. [16.1_main.py](src/16.1_main.py) - модуль для проверки работы, полученный по заданию
2. [class_config.py](src/class_config.py) - модуль для определения классов
3. [utils.py](src/utils.py) - модуль содержит две функции: Первая для чтения json-файла, Вторая для работы с полученными данными и получения объектов класса


## Задания, на взгляд студента, реализованы странно и нелогично. Но кто бы его спрашивал;)


## Установка и использование. 
Склонируйте себе репозиторий и наслаждайтесь!

## Установка зависимостей.
[requirements.txt](requirements.txt) содержит зависимости проекта. 
Для установки можно использовать следующий код: 
```
pip install -r requirements.txt
```

## Примеры использования. 
Примеры использования отражены в тестовых документах в папке [tests](tests).
Результаты тестирования указаны в [index.html](htmlcov/index.html)
На момент проверки автором общий процент равен 99%

## Лицензия.
Проект не лицензируется, так как создан в рамках обучения и не несет особо важной информации, кроме как для студента-создателя.
