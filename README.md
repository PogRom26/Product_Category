# Проект для обучения работы с классами

Проект содержит следующий функционал:
1. [main.py](src/main.py) - базовый модуль для проверки работы классов. Классы импортированы из [class_config.py](src/class_config.py)
2. [class_config.py](src/class_config.py) - модуль для определения классов
3. [utils.py](src/utils.py) - модуль содержит две функции:
   4. Первая для чтения json-файла;
   5. Вторая для работы с полученными данными и получения объектов класса
